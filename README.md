# FamiTube Web Curation Studio

Standalone web admin dashboard for curating videos, channels, playlists, and parental defaults for FamiTube.

## Quick Start

```bash
npm run dev
```

Open `http://localhost:3000`.

By default, the dashboard connects to the FamiTube API at `http://localhost:4000`. To point it at a different API URL, pass `?api=https://your-api-url` in the browser URL (saved to `localStorage`).
